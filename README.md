# ⚡ Data Structures & Algorithms in C

Implementation of core computer science data structures, memory management, and algorithmic problem-solving using C.

---

## 🛠 Topics Covered

* **Linear Data Structures:** Arrays, Singly & Doubly Linked Lists, Stacks, Queues, Circular Queues.
* **Non-Linear Data Structures:** Binary Search Trees (BST), Tree Traversals (Inorder, Preorder, Postorder).
* **Algorithms:** Searching (Linear, Binary), Sorting (Bubble, Selection, Insertion, Merge, Quick Sort).
* **Memory Management:** Dynamic memory allocation using `malloc`, `calloc`, `realloc`, and `free`.
